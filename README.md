
# Онлайн чат

Этот репозиторий содержит простое приложение для онлайн чата, реализованное на C++ и Qt. Проект состоит из двух основных компонентов:
1. **Сервер** - обрабатывает сообщения и управляет клиентами.
2. **Клиент** - графический интерфейс для пользователей для отправки и получения сообщений.

## Возможности
- Обмен сообщениями в реальном времени с использованием Boost.Asio.
- Графический интерфейс на базе Qt Framework.
- Уведомления о присоединении/выходе пользователей.
- Отображение временных меток для сообщений.

## Начало работы

### Необходимые компоненты
- Компилятор C++ с поддержкой стандарта C++14 или выше.
- [Qt Framework](https://www.qt.io/) (рекомендуется версия 5.15+).
- [Boost Library](https://www.boost.org/) (рекомендуется версия 1.70+).

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ilya-kan07/Online_chat.git
   cd Online_chat
   ```

2. Сборка проекта:
   - Для **сервера** используйте CMake:
     ```bash
     mkdir build
     cd build
     cmake ..
     make
     ./server
     ```

   - Для **клиента** используйте Qt Creator:
     1. Откройте `online-chat.pro` в Qt Creator.
     2. Настройте проект и соберите его.

### Использование

1. **Запустите сервер:**
   Выполните серверный исполняемый файл на нужном порту (по умолчанию: 8888).

2. **Запустите клиент:**
   Откройте клиентское приложение, подключитесь к серверу, введя IP-адрес и порт, и начните общение!
